Detailed Description

Device definition for the Hosyond 2.8inch ESP32-S3 Display.

Author
Rick Wargo

Information about this board can be found at https://www.lcdwiki.com/2.8inch_ESP32-S3_Display. The product page is accessible via the Hosyond site at https://hosyond.com/#:~:text=ESP32%20Display.

This will not work for the Hosyond 3.5inch display as the pins are different. Fortunately, both boards share the ES8311 for audio, however, this board uses an FM8002E for the power amplifier, compared to SC8002B. The PA's are pin compatible and are also enabled low via the Hosyond boards, so it should only be another pin remapping; the difference being the SC8002B can driver a higher output up to 3W.

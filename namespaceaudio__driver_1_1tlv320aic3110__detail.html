◆ RegAddr

using RegAddr = uint16_t

Page + register address pair, packed as (page << 8) | reg. A plain scalar (rather than a class type) so that the RegAddr constants below are never odr-used, which avoids requiring out-of-class definitions on pre-C++17 compilers (e.g. the ESP32 Arduino core's default -std=gnu++11). Defined at namespace scope (rather than as a static member function) so it is already complete when used in the static member initializers below.

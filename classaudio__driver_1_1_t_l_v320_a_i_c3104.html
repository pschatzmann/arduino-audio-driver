Detailed Description

Header only C++ driver for the TLV320AIC3104 audio codec.

The TLV320AIC3104 uses a paged 8 bit register map (page select register at page 0 / register 0, pages 0 and 1 are used by this device). Provides soft reset, PLL/clock configuration (P/Q/J/D PLL plus a shared ADC/DAC "NCODEC" divider), DAI (I2S) format configuration and output/input path configuration including volume and mute control for the headphone (HPLOUT/HPROUT) and fully differential line (LOP/M) outputs, and the microphone/line input PGAs.
